# OpenBike — app icon package

Master mark rebuilt as clean vector (strokes + fully outlined paths) and rendered to every
size/format needed to publish the Flutter app on **iOS, Android, macOS, Windows and Linux**.

This directory is **source, not build output** — despite once being named `dist/`. What the
app actually builds against is generated from it; see "Regenerating" below.

## Master assets (`branding/`)
| File | Spec | Use |
|---|---|---|
| `app_icon.png` | 1024×1024, flattened, **no alpha channel** | App Store / master square icon |
| `app_icon_foreground.png` | 1024×1024, transparent, mark inside centre 683px | Adaptive-icon foreground |
| `app_icon_monochrome.png` | 1024×1024, transparent, single-colour (white) | Android 13+ themed icons |
| `small/app_icon_small_*.png` | thicker-stroke variant, 16/32/48 | Favicons / tray / small sizes |

The 683px content box on the foreground is the Android adaptive safe zone (72/108dp). The
generator is configured with `adaptive_icon_foreground_inset: 0` to avoid insetting it twice.

## Vector source (`branding/vector/`)
- `openbike_source.svg` — editable, stroke-based (open in Figma/Illustrator).
- `openbike_outlined.svg` — **paths outlined** (no live strokes), for print/handoff.
- `openbike_foreground.svg`, `openbike_monochrome.svg`, `openbike_background.svg` — layer sources.

This is the only editable copy of the mark. The 1024px rasters cannot be reversed back into it.

## Per-platform PNGs
Reference/handoff renders. Most platforms are generated by tooling rather than copied from
here — the exceptions are called out below.

- `branding/ios/` — 20→1024 (all opaque, no alpha).
- `branding/android/mipmap-*/` — `ic_launcher` (legacy) + adaptive `ic_launcher_foreground` / `_background` / `_monochrome` at mdpi→xxxhdpi.
- `branding/android/play_store_512.png` — **uploaded by hand** to the Play Console; not part of any build.
- `branding/macos/` — 16→1024.
- `branding/windows/` — 16→256.
- `branding/linux/` — 16→512, **the source for `linux/icons/hicolor/`** (flutter_launcher_icons has no Linux support, so those are copied in and installed into the bundle by `linux/CMakeLists.txt`).

## Regenerating

The launcher-icon config lives at the repo root and reads the masters from `assets/icon/`,
which are copies of the three master PNGs above. To change the mark: edit the vector source,
re-export the masters here, copy them to `assets/icon/`, then run

```
dart run flutter_launcher_icons     # Android, iOS, macOS, Windows
dart run flutter_native_splash:create
```

Both are configured to skip web, which is out of scope for now. Linux is not covered by either
tool — refresh `linux/icons/hicolor/<size>x<size>/apps/` from `branding/linux/` by hand.

Brand colours: background **#000000**, accent **#ff751f**, mark **#ffffff**.
